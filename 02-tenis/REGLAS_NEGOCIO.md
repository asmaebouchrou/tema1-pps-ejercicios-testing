# Reglas de negocio: Marcador de tenis: juego, set y tie-break

- **RN-T01:** puntos del juego: 0, 15, 30, 40 y juego; en 40-40 hay iguales.
- **RN-T02:** despues de iguales hacen falta dos puntos consecutivos para ganar el juego; si quien pierde el punto tenia ventaja, se vuelve a iguales.
- **RN-T03:** el set se gana con al menos seis juegos y diferencia de dos, salvo 6-6, que inicia tie-break.
- **RN-T04:** tie-break al menos siete puntos y diferencia de dos; gana el set quien gana el tie-break.
- **RN-T05:** partido al mejor de tres sets. Tras finalizar no se aceptan nuevos puntos.
- **RN-T06:** solo se aceptan jugadores identificados como 0 o 1.
