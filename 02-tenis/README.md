# Ejercicio 6. Marcador de tenis

Este proyecto incluye el código necesario, pero **no** los tests solicitados en el ejercicio. Debes escribirlos en `tests/test_actividad.py`.

Lee `ENUNCIADO.md` y `REGLAS_NEGOCIO.md`. Desde esta carpeta prepara un entorno virtual e instala dependencias:

```bash
python3 -m venv .venv
source .venv/bin/activate
# En Fish: source .venv/bin/activate.fish
python -m pip install -r requirements.txt
```

Ejecuta las pruebas desde la raíz de este proyecto con `python -m pytest -v tests/test_actividad.py`.
